# L4.3 — ExecPlan P2: Intelligence (Generation, Gateway, ToS)

**1. Objective & scope.** Build the LLM gateway with TOKENKILLER segmentation, the local-vision ToS engine, and the end-to-end generation pipeline that produces content bundles with per-platform captions/hashtags and a ToS verdict.

**2. Preconditions.** `L4.2` complete. GPU or adequate CPU for local vision model provisioned.

**3. Invariants touched.** LBI-09 (prefix-cache discipline), LBI-11 (ToS gate before ship).

**4. Dependencies.** LLM provider router (+ local model option), TOKENKILLER prefix assembler, local vision model (NSFW/ToS classification), media pipeline (Rust), pgvector (for S2 retrieval later wired in P3).

**5. Build steps.**
1. LLM gateway: multi-provider router with cost/latency policy + local fallback (`L2.5`). → `gateway.done`
2. TOKENKILLER assembler: S0→S1→S2→S3 segments, 64-token block alignment, append-only, per-(model,platform) prefix versioning (`L3.5 §4`). → `tokenkiller.done`
3. Master Prompt Engine + playbook engine (persona S0, platform/ToS rules S1). → `prompts.done`
4. Local vision ToS engine: classifies asset, emits `pass|review|block` + reasons (`L2.10`); runs in-netns, no third-party upload. → `tos.done`
5. Generation pipeline: prompt → media → per-platform caption/hashtag variants → ToS scan → persist `content_bundle` + `post_target` rows. → `pipeline.done`
6. Pre-Post Script hook (Fanvue MCP) applied before any Fanvue publish. → `prepost.done`

**6. Config & secrets.** Provider keys in secret store; local model weights on box (not in git); prefix cache store sized for exemplar growth.

**7. Per-step validation.**
```bash
# prefix cache-hit on a repeat generation (same model/platform, new task):
cargo test -p tokenkiller cache_hit_ratio        # asserts > 0.97
# ToS block path:
axiom gen --fixture nsfw_block | jq -e '.tos.verdict=="block"'
# no third-party egress during vision scan:
sudo ip netns exec axiom-egress ss -tp | grep -qv ESTAB
```

**8. Integration validation.** Generate a bundle for a model targeting all 10 platforms → captions truncated to each platform limit, hashtags per platform rules, one ToS verdict; a `block` fixture prevents downstream approval (LBI-11).

**9. Rollback.** Disable gateway route (feature flag) to halt generation; ToS engine defaults to `block` on failure (fail-safe, never `pass`); revert prompt versions.

**10. Idempotency.** Generation keyed by request id; re-run returns existing bundle. Prefix versions content-addressed; unchanged S0–S2 reuse cache.

**11. Security checklist.** ToS fail ⇒ `block` (never open); vision runs locally in-netns; no prompt/PII in third-party logs beyond chosen provider; provider keys scoped.

**12. Performance checks.** Prefix cache-hit > 97%; median generation within budget; vision scan p95 measured.

**13. Artifacts.** Gateway, TOKENKILLER assembler, ToS engine, generation pipeline, `.axiom/markers/L4.3/*`.

**14. Done-criteria.** 10-platform bundle generates with correct per-platform shaping; cache-hit target met; ToS block gate proven.

**15. Hand-off.** Bundles + verdicts exist → `L4.4` adds human control (Relay), learning (viral loop), and observability.
