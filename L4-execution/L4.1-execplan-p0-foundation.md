# L4.1 — ExecPlan P0: Foundation

**1. Objective & scope.** Stand up the single-box host, data layer, auth, tenancy isolation, and CI. End state: an empty but secure multi-tenant spine that every later plane plugs into.

**2. Preconditions.** Fresh Hetzner box (Ubuntu 24.04). No prior `.axiom/markers/L4.1/*`. DNS for the app domain delegated to Cloudflare. SSH key-only access.

**3. Invariants touched.** LBI-02 (RLS tenant isolation), LBI-08 (audit hash chain), LBI-10 (marker gating).

**4. Dependencies.** Coolify (self-hosted PaaS), Docker, Postgres 16 + TimescaleDB + pgvector, Better Auth, Cloudflare Tunnel, R2 bucket, pnpm, Rust toolchain, GitHub Actions runner.

**5. Build steps.**
1. Harden host: ufw default-deny inbound except SSH; Cloudflare Tunnel for ingress (no public ports). → marker `host.done`
2. Install Coolify; register the box; wire R2 + Postgres as managed resources. → `coolify.done`
3. Provision Postgres; run extensions block (`L3.1 §0`); create `axiom_app` / `axiom_migrator` roles. → `pg.done`
4. Apply base migrations = entity tree DDL (`L3.1 §1–9`). → `schema.done`
5. Generate + apply RLS policies for **every** org-scoped table (`L3.1 §10`). → `rls.done`
6. Stand up Better Auth (self-hosted) with org/user model + RBAC roles. → `auth.done`
7. Seed audit chain genesis row (`prev_hash = 0x00…`). → `audit.done`
8. CI pipeline: typecheck, `cargo check`, `sh -n`, migration test, RLS-coverage test. → `ci.done`

**6. Config & secrets.** Secrets via Coolify's encrypted store → env at runtime; KEK in KMS, per-org DEK created on org insert (`L2.12`). No secret in git; `.env.example` only.

**7. Per-step validation.**
```bash
ufw status | grep -q 'Status: active'
psql -c '\dx' | grep -Eq 'timescaledb|vector'
psql -tAc "select count(*) from pg_policies where policyname='org_isolation'"  # == #org-scoped tables
psql -tAc "select row_hash is not null from audit_log order by id limit 1"
```

**8. Integration validation.** Create two orgs; as org A, attempt to read org B rows → 0 rows (RLS proof). Login flow issues session; RBAC denies analyst a write route.

**9. Rollback.** All DDL in transactional migrations with `down`. Coolify snapshot before phase; restore reverts host state. Markers deleted on rollback to force clean re-run.

**10. Idempotency.** Each step SKIPs on matching marker, FAILs on checksum drift. Migrations tracked by version table; re-apply is a no-op.

**11. Security checklist.** No public inbound ports; RLS FORCE on; app role can't bypass RLS; audit genesis present; secrets not in repo; TLS via Cloudflare.

**12. Performance checks.** Cold query p95 < 20ms on seed data; connection pool sized to box.

**13. Artifacts.** Running host, schema, auth, CI, `.axiom/markers/L4.1/*`.

**14. Done-criteria.** RLS cross-tenant test green; CI green; audit chain verifies; all P0 markers present.

**15. Hand-off.** Foundation ready → `L4.2` mounts the network plane and connectors.
