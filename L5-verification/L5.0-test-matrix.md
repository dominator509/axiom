# L5.0 — Verification: Test Matrix

> Maps every canonical Load-Bearing Invariant (LBI-01..12) and every requested feature (A1–A7 + preserved catalog) to concrete tests. A release is blocked unless this matrix is green. Tests are the executable definition of "done."

| LBI-10 | Greenfield marker discipline | a satisfied step skips; marker checksum drift fails closed | build |

LBI-09 runtime capture is exercised by the gateway observer tests, the synchronous and worker generation wiring tests, and the model-scoped cache-telemetry API tests. The persistent daily aggregate uses provider-reported counters only; a successful response without usable counters remains in the unknown denominator and makes the cohort ratio unavailable. These tests verify capture and fail-closed reporting, but actual >97% acceptance still requires repeat generations through an approved provider account.

## 3. Feature-preservation regression

A checklist test asserts every v1 feature (F-01..F-88 in `L1.1`) resolves to a live route/worker/UI in v2. The owner extensions F-89 (localization), F-90 (FanThynks platform affiliate/referral control), F-91 (Patreon creator/community integration), and F-92 (Beacon CRM account records connector) have their own acceptance rows in the execution plan and must also resolve before the product is called feature-complete. No v1 capability may 404. This is the machine-checkable proof that "no features were removed" plus the new owner extensions.

## 4. Non-functional gates

- Load: 4 generation batches and 20 publish targets per model per day, up to 20 models; measure sustained and burst load against the latency limits in `L1.2` and `L4`.
- Availability: core publishing path target ≥99.5%; report the measured sample window and provider availability separately. No minimum observation period is a release gate.
- Recovery: restart mid-publish ⇒ no dupes, no lost jobs (durability of PG queue).
- Security scan: dependency audit, secret scan, RLS coverage, egress default-deny.
- Cost telemetry: monthly infra projection within the `A1` cost-model band (`appendices/A1`).

## 5. CI wiring

All of §1–§4 run in CI. Phase advancement (`L4`) requires the relevant subset green; release requires the full matrix green.
