## 3. Feature-preservation regression

A checklist test asserts every v1 feature (F-01..F-88 in `L1.1`) resolves to a live route/worker/UI in v2. No v1 capability may 404. This is the machine-checkable proof that "no features were removed."

## 4. Non-functional gates

- Load: sustained generation + publish at target rate, p95 within budget.
- Recovery: restart mid-publish ⇒ no dupes, no lost jobs (durability of PG queue).
- Security scan: dependency audit, secret scan, RLS coverage, egress default-deny.
- Cost telemetry: monthly infra projection within the `A1` cost-model band (`appendices/A1`).

## 5. CI wiring

All of §1–§4 run in CI. Phase advancement (`L4`) requires the relevant subset green; release requires the full matrix green.
