# L5.2 — Acceptance Criteria & Security Audit

> The final gate. AXIOM is accepted only when every criterion below is demonstrably met. This doubles as the security audit checklist.

## 1. Functional acceptance

- [ ] Runs on a **single box** (Hetzner + Coolify) with Cloudflare + R2; no per-service metered PaaS required.
- [ ] All **10 platforms** connect, validate, and publish (or assist honestly for Snapchat).
- [ ] **Link-in-bio Native** works with zero external providers; Fanlynks, Linktree, and Beacons remain blocked until their real adapters and unified analytics are implemented.
- [ ] **On-the-go control** from Telegram, iMessage, Signal, and Discord: approve / reject / edit / reschedule / publish-now.
- [ ] On generation, a **card** with preview + per-platform mock captions + hashtags + ToS verdict is pushed to the operator's channel.
- [ ] **Auto crash/bug reporting** captures injected faults; structured logs + traces + dashboards live.
- [ ] **Self-improving viral loop** turns performance into exemplars that measurably bias later generations; bandit explores + exploits.
- [ ] Every **v1 feature (F-01..F-88)** resolves in v2 — nothing removed.

## 2. Non-functional acceptance

- [ ] Prefix cache-hit **> 97%** on repeat generations (LBI-09).
- [ ] Cross-tenant read returns **0 rows** under RLS (LBI-02).
- [ ] Egress **fail-closed** proven; kill-switch halts publishing (LBI-03, LBI-12).
- [ ] Exactly-once publish under retry/double-tap (LBI-05).
- [ ] Monthly infra cost within the modeled band (`appendices/A1`), materially below v1.
- [ ] RPO ≤ 5 min, RTO ≤ 60 min in a rehearsed drill (`L5.1`).

## 3. Security audit checklist

- [ ] No plaintext credentials at rest or in logs (LBI-01); envelope encryption verified.
- [ ] Every org-scoped table has `org_isolation` RLS with `FORCE`; app role can't bypass (LBI-02).
- [ ] Egress default-deny; only whitelisted hosts reachable when enabled (LBI-03).
- [ ] Relay commands signed, single-use (nonce), expiring; replay + expiry rejected (LBI-06).
- [ ] Audit log hash chain verifies; tamper detectable (LBI-08).
- [ ] ToS engine fails to **block**, never **pass** (LBI-11).
- [ ] Adult-content Consent & Records Vault populated + access-controlled (`L0.1`).
- [ ] Secrets in KMS/secret store, not git; dependency + secret scans clean.
- [ ] Agent `requires_approval` tools cannot publish directly; RBAC + tier enforced (LBI-04).

Building `infra/Dockerfile.vision` and running `scripts/rehearse-vision.mjs
--isolated-fixture` exposed a real HTTP 400 on `/vision/nsfw-detect` for a relative

locally built `axiom-vision-engine:rehearsal-45f96d5` tag (rebuilt with the fix),
read-only mounts, no container network access and an ephemeral token. The probe
container was removed. Recreate that tag from current source before rerunning;

`sha256:2674d750b464d8a81de8b09d4a6bfa00c07dc7a0a28f775729e8b6cf6a5a1f39`.

no running service was recreated, and full worker-to-vision execution remains open.
