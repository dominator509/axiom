# L3.1 — Database DDL & RLS Policies

> Concrete Postgres realization of the entity tree in `L2.2`. Postgres 16 + TimescaleDB + pgvector. All multi-tenant tables carry `org_id` and are protected by Row-Level Security (LBI-02). DDL is authoritative; migrations in `L4` apply it in ordered, marker-gated steps.

## 0. Extensions & roles

```sql
CREATE EXTENSION IF NOT EXISTS "uuid-ossp";
CREATE EXTENSION IF NOT EXISTS pgcrypto;
CREATE EXTENSION IF NOT EXISTS vector;      -- pgvector (viral loop)
CREATE EXTENSION IF NOT EXISTS timescaledb; -- hypertables (metrics)

-- Application connects as a non-superuser that CANNOT bypass RLS.
-- (Superuser/table-owner bypass RLS by default; app role must not own tables.)
CREATE ROLE axiom_app NOLOGIN;
CREATE ROLE axiom_migrator NOLOGIN;  -- owns schema, runs DDL
```

Tenancy context is set per transaction by the BFF/worker:

```sql
-- set once per request/job, inside the txn, before any query
SELECT set_config('app.org_id', $1, true);   -- true = local to txn
```

## 1. Tenancy & identity

```sql
  id           uuid PRIMARY KEY DEFAULT uuid_generate_v4(),
  name         text NOT NULL,

  id           uuid PRIMARY KEY DEFAULT uuid_generate_v4(),

                 ('owner','manager','operator','analyst','agent')),
  created_at   timestamptz NOT NULL DEFAULT now(),

  id           uuid PRIMARY KEY DEFAULT uuid_generate_v4(),
  org_id       uuid NOT NULL REFERENCES org(id) ON DELETE CASCADE,
  handle       text NOT NULL,
  persona_ref  text NOT NULL,           -- S0 prefix id (TOKENKILLER, L2.5)
  status       text NOT NULL DEFAULT 'active',
  created_at   timestamptz NOT NULL DEFAULT now(),
  UNIQUE (org_id, handle)
);
```

## 3a. Network egress config (per-model isolation, L2.6)

> Spec-update (2026-08-06, evidence): `L2.2` §entity-tree lists `model_network_configs`; this file previously lacked its DDL and the live DB lacked the table. Added to close the L2.6 gap (wireguard/vpn/proxy modes were designed but never specified in DDL).

```sql
CREATE TABLE model_network_configs (
  id                      uuid PRIMARY KEY DEFAULT uuid_generate_v4(),
  org_id                  uuid NOT NULL REFERENCES org(id) ON DELETE CASCADE,
  model_id                uuid NOT NULL REFERENCES model_profile(id) ON DELETE CASCADE,
  -- egress mode: direct | socks5 | http | https | wireguard | vpn (L2.6)
  egress_mode             text NOT NULL DEFAULT 'direct'
                          CHECK (egress_mode IN
                            ('direct','socks5','http','https','wireguard','vpn')),
  proxy_type              text,        -- socks5/http/https
  proxy_addr              text,        -- host:port of the bound proxy
  wg_public_key           text,        -- public key (plaintext; not secret)
  wg_endpoint             text,        -- tunnel endpoint host:port
  wg_allowed_ips          text,        -- CIDR list routed through the tunnel
  wg_persistent_keepalive integer,
  expected_egress_ip      text,        -- drift policy: warn if echo IP differs
  failover_proxy_addrs    text[] NOT NULL DEFAULT '{}',  -- approved alternate egress
  -- envelope-encrypted creds blob: proxy user/pass, WG private key + preshared,
  -- VPN tunnel config. Decrypted only in the Rust egress worker; zeroized (LBI-05).
  enc_creds               bytea,
  enc_nonce               bytea,
  dek_id                  text,
  -- live health (Network & Security tab, L1.1 F-02)
  healthy                 boolean NOT NULL DEFAULT false,
  last_check              timestamptz,
  latency_ms              integer,
  last_egress_ip          text,
  fail_count              integer NOT NULL DEFAULT 0,
  last_error              text,
  created_at              timestamptz NOT NULL DEFAULT now(),
  updated_at              timestamptz NOT NULL DEFAULT now(),
  UNIQUE (model_id)       -- one egress config per model profile
);

CREATE INDEX idx_model_network_configs_org_id ON model_network_configs(org_id);

ALTER TABLE model_network_configs ENABLE ROW LEVEL SECURITY;
ALTER TABLE model_network_configs FORCE ROW LEVEL SECURITY;
CREATE POLICY org_isolation ON model_network_configs
  USING      (org_id = current_setting('app.org_id')::uuid)
  WITH CHECK (org_id = current_setting('app.org_id')::uuid);

GRANT SELECT, INSERT, UPDATE, DELETE ON model_network_configs TO axiom_app;
```

> Fail-closed contract: the Rust egress plane refuses to execute a model's
> outbound work outside its bound egress when the health check fails — never a
> silent host-route fallback (LBI-02).

## 4. Content lifecycle

```sql
CREATE TABLE asset (
  id            uuid PRIMARY KEY DEFAULT uuid_generate_v4(),
  org_id        uuid NOT NULL REFERENCES org(id) ON DELETE CASCADE,
  model_id      uuid NOT NULL REFERENCES model_profile(id) ON DELETE CASCADE,
  kind          text NOT NULL CHECK (kind IN ('image','video','audio')),
  r2_key        text NOT NULL,
  sha256        bytea NOT NULL,          -- content hash → idempotency (LBI-05)
  nsfw_rating   text,                    -- local vision (L2.10)
  created_at    timestamptz NOT NULL DEFAULT now(),
  UNIQUE (org_id, sha256)
);

CREATE TABLE content_bundle (
  id            uuid PRIMARY KEY DEFAULT uuid_generate_v4(),
  org_id        uuid NOT NULL REFERENCES org(id) ON DELETE CASCADE,
  model_id      uuid NOT NULL REFERENCES model_profile(id) ON DELETE CASCADE,
  asset_id      uuid NOT NULL REFERENCES asset(id),
  captions      jsonb NOT NULL,          -- per-platform variants
  hashtags      jsonb NOT NULL,
  tos_report    jsonb,                   -- ToS engine verdict (L2.10)
  state         text NOT NULL DEFAULT 'generated' CHECK (state IN
                  ('generated','approved','rejected','scheduled',
                   'publishing','published','failed')),
  created_at    timestamptz NOT NULL DEFAULT now()
);

CREATE TABLE post_target (
  id            uuid PRIMARY KEY DEFAULT uuid_generate_v4(),
  org_id        uuid NOT NULL REFERENCES org(id) ON DELETE CASCADE,
  bundle_id     uuid NOT NULL REFERENCES content_bundle(id) ON DELETE CASCADE,
  platform      text NOT NULL,
  connection_id uuid NOT NULL REFERENCES platform_connection(id),
  scheduled_for timestamptz,
  state         text NOT NULL DEFAULT 'pending' CHECK (state IN
                  ('pending','publishing','published','failed','skipped')),
  remote_id     text,                    -- platform post id when published
  error         text,
  -- idempotency key = H(model_id, asset_sha, platform, slot) (LBI-05)
  idem_key      bytea NOT NULL,
  UNIQUE (org_id, idem_key)
);
```

## 8. Queue & idempotency (Postgres-backed, L2.9 / L3.4)

> Spec-update (2026-08-08, evidence): `job.id` and `audit_log.id` are `uuid` PKs,
> not `bigint GENERATED ALWAYS AS IDENTITY`. The implementation generates uuid
> PKs client-side via `gen_random_uuid()` (drizzle default), which keeps inserts
> independent of DB sequences and matches every other table's PK convention.
> Changing to bigint identity would churn every FK and the claim_job resolver
> for no functional gain — the divergence is deliberate. `job.state` CHECK
> includes `'failed'` in addition to the DDL's four states because the worker's
> DLQ view (L3.4 §3) legitimately uses it. `max_attempts` defaults to 8 per DDL.

```sql
CREATE TABLE job (
  id            bigint GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
  org_id        uuid NOT NULL,
  kind          text NOT NULL,
  payload       jsonb NOT NULL,
  run_after     timestamptz NOT NULL DEFAULT now(),
  attempts      int NOT NULL DEFAULT 0,
  max_attempts  int NOT NULL DEFAULT 8,
  locked_by     text,
  locked_at     timestamptz,
  state         text NOT NULL DEFAULT 'ready' CHECK (state IN
                  ('ready','running','done','dead')),
  dedupe_key    bytea,
  created_at    timestamptz NOT NULL DEFAULT now(),
  UNIQUE (org_id, dedupe_key)
);
CREATE INDEX job_pick ON job (state, run_after) WHERE state = 'ready';

CREATE TABLE idempotency_ledger (
  org_id   uuid  NOT NULL,
  idem_key bytea NOT NULL,
  result   jsonb NOT NULL,
  created_at timestamptz NOT NULL DEFAULT now(),
  PRIMARY KEY (org_id, idem_key)
);
```

## 9. Hash-chained audit log (LBI-08)

> Spec-update (2026-08-08, evidence): see §8 — `audit_log.id` is a uuid PK
> (client-generated), not bigint identity; the hash-chain verifier orders by
> `(ts, id)` and the genesis anchor is a fixed literal, both unaffected by the
> PK type.

```sql
CREATE TABLE audit_log (
  id         bigint GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
  org_id     uuid NOT NULL,
  actor_ref  text NOT NULL,
  action     text NOT NULL,
  target     text,
  detail     jsonb,
  ts         timestamptz NOT NULL DEFAULT now(),
  prev_hash  bytea NOT NULL,
  row_hash   bytea NOT NULL     -- H(prev_hash || canonical(row)) (L2.12)
);
```

## 10. RLS policy pattern (applied to every org-scoped table)

```sql
ALTER TABLE platform_connection ENABLE ROW LEVEL SECURITY;
ALTER TABLE platform_connection FORCE ROW LEVEL SECURITY;

CREATE POLICY org_isolation ON platform_connection
  USING      (org_id = current_setting('app.org_id')::uuid)
  WITH CHECK (org_id = current_setting('app.org_id')::uuid);

GRANT SELECT, INSERT, UPDATE, DELETE ON platform_connection TO axiom_app;
```

> The identical `org_isolation` policy is generated for **every** table carrying `org_id`. `FORCE ROW LEVEL SECURITY` ensures even the table owner is subject to it in app paths. A migration test (`L5`) asserts that no org-scoped table is missing the policy — a fail-closed guarantee for LBI-02.

## 11. Referential & integrity notes

- All `ON DELETE CASCADE` from `org` guarantees clean tenant offboarding (GDPR/erasure, L0.1).
- `asset.sha256` unique-per-org gives content-addressed dedupe feeding the idempotency key.
- `relay_command.nonce` unique-per-org enforces single-use signed commands (replay defense).
- `post_target.idem_key` unique-per-org makes double-publish structurally impossible (LBI-05).
