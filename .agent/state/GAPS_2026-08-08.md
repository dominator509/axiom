## Gap list (fix order)

### G-1 [HIGH] Rust planes not deployed as services + worker has no service
Evidence: `ls /etc/systemd/system | grep axiom` → only `axiom-api.service`, `axiom-egress.service`.
Media/vision/scraper binaries exist in `target/debug/` but never run; worker never runs in prod.
Fix: build release binaries, write systemd units (media-plane :8100, vision-engine :8101,
scraper :8102, worker), enable + start, health-check each.

### G-2 [HIGH] Media-plane lacks video (F-14 watermark, F-29 clip) — image-only
Evidence: `crates/media-plane/src/main.rs` only handles image paths; Cargo.toml has no
ffmpeg dep; ffmpeg not installed on host. Fix: install ffmpeg, add video transcode /
watermark / clip endpoints (via ffmpeg subprocess), add Rust tests.

### G-3 [HIGH] Vision-engine is a statistics function, not a vision model
Evidence: `heuristic_nsfw_score()` = brightness/variance; no model inference. Fix: integrate
a real self-hosted vision model (ONNX Runtime + real model download, or LLM-gateway vision
fallback), keep stats as pre-analysis, add tests. L2.10 says self-hosted → ONNX preferred.

### G-4 [HIGH] Scraper hardcodes followers/posts = 0 (F-17/F-18 broken)
Evidence: `followers: 0, following: 0, posts: 0` literals in scrape_social; parse_profile_page
returns only name/bio/avatar. Fix: real per-platform HTML/JSON parsing (meta tags, embedded JSON),
graceful degradation with honest error, tests.

### G-5 [MED-HIGH] Fanvue MCP client is REST, not the MCP protocol (F-03, F-31)
Evidence: client.ts fetches REST paths; mcp-server package already has JSON-RPC surface.
Fix: rewrite client as JSON-RPC 2.0 MCP client (initialize handshake, tools/list, tools/call)
matching McpServer; keep credential schema; contract tests against a local JSON-RPC server.

### G-6 [MED-HIGH] Pre-Post hook not wired: no pre_post_run writes, no isolated execution
Evidence: `pre_post_run` table empty/unused; PrePostHook class unused by worker. Fix: worker
executor runs PrePostHook pre/post around publish; records every run in pre_post_run;
media-plane staging call when configured (Rust-isolated execution path, L2.10 v2).

### G-7 [MED] TOKENKILLER not wired in gateway: /chat serves plain messages; cache-hit unmeasurable
Evidence: routes.ts passes messages straight to gateway.chat(); PrefixCache (cache.ts) and
prompts.ts S0–S3 exist but gateway never assembles or measures. Fix: gateway assembles
S0–S3 via prompts.ts when a profile is provided, uses PrefixCache with cacheKey, emits
cache-hit-rate per call, exposes `/stats` ratio; test that stable prefix hits and S3-only
misses drive ratio toward the L2.5 >97% target.

### G-8 [MED] L3.0 contract conventions missing: problem+json, Idempotency-Key, rate limits, cursor
Evidence: no `application/problem+json`/`correlation_id` anywhere in api; no
`Idempotency-Key` header handling; no 429 rate-limit middleware; pagination is limit-only
(fans, audit), no cursor. Fix: error envelope middleware (problem+json + correlation_id),
idempotency-key middleware for mutations, per-token rate-limit buckets, cursor pagination
on list routes; tests.

### G-9 [LOW-MED] Connectors registered only in worker process, not API; worker not deployed
Evidence: registerConnectors() called only in runner.ts; api/index.ts never calls it.
Fix: call registerConnectors() in API startup too (idempotent registry), so API-side
connector lookups work; covered by G-1 worker service.
